# 常见问题

[返回首页](../README.md)

### 可以录无露脸的语音连麦吗？

只要观众端可播放的直播流包含音频，录制器就尝试保存该混合音轨。首次使用必须选一段实际连麦样本试听验证。不会保存独立麦位，也不能保证所有房型或风控状态都可解析。

### 为什么没有录到文件？

先确认正在开播、电脑直播间地址正确、服务器能访问、磁盘可用空间大于阈值。再查录制日志和异常隔离记录。纯静音、损坏或很短的样本可能被过滤；不要只根据列表为空判断服务没启动。

### 为什么 30 分钟文件很多，却不是多场直播？

文件分段与录制连接都不等同于真实直播场次。默认每 30 分钟分段，断线重连也会新建连接记录。页面按连接组织素材，不把每次重连宣称成房主重新开播。

### 是不是所有录音都能变成“成功案例”？

不是。闲聊、碎片观点和只有技术细节的材料不一定具备完整商业案例。系统应保留阶段和证据，不能编造客户、成交金额或收益。材料不足时可能只有商业总结或待补线索；需要补充真实信息。

### 网页打不开 / 登录失败？

完整部署的入口是 `https://你的域名/recorder-admin/`。依次检查 HTTPS 证书、反向代理、API 服务、管理密码以及 `ADMIN_ORIGIN`。普通演示入口 `http://127.0.0.1:8788/` 使用虚构数据，不能代替真实管理后台。

### 为什么 403“请求来源不匹配”？

`ADMIN_ORIGIN` 必须与地址栏中的协议、域名和端口一致，不含路径。后台使用来源检查和 CSRF 保护；不要为解决地址配置错误而删除这些保护。

### 为什么显示模型未准备好？

确认 `models/asr`、`models/vad`、`models/punc` 中有脚本要求的 ONNX 文件，并且 `douyinanalysis` 用户可读。运行模型下载脚本，查看失败原因。不要用网页反复提交任务代替安装模型。

### 任务停在等待预算或余额不足？

分别检查网页预估预算、单任务预算与 DeepSeek 真实账户余额。充值不会自动替你修改应用预算；改变预算也不会给 API 账户充值。先核实失败原因，再恢复任务。

### 11 点没有群消息？

检查首次发送日期、群绑定、机器人在线状态及最近发送状态。未配置凭据不会发送；首次启用不会自动补发所有历史。11 点之后才完成的内容进入后续日报。出现“发送结果待确认”时先核实群内消息。

### 支持多直播间、视频录制、说话人识别吗？

当前录制器配置一个直播间。多房间可运行独立进程、配置和目录，未提供统一多房间管理界面。不提供视频录像、麦位分轨或说话人识别。

### 如何提一个有效的 Issue？

说明系统、Python 版本、使用步骤、预期与实际结果，附脱敏后的错误类型。不要上传真实录音、客户文字、密码、Bot Secret、API Key、Cookie 或带签名的直播播放 URL。参见 [贡献指南](../CONTRIBUTING.md)。
